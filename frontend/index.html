Satellite Flood Detection & Monitoring

Sentinel-1 SAR · U-Net

Upload a georeferenced two-band GeoTIFF in VV, VH order. The saved model expects 512×512×2, clips/scales VV −30…0 dB and VH −35…−5 dB to [0,1], and returns a 512×512×1 flood-label probability (default threshold 0.50). RGB photographs are incompatible. Held-out India test set: 14 Sen1Floods11 scenes; pooled IoU 0.609, Dice/F1 0.757, precision 0.890, recall 0.658. These benchmark metrics do not establish performance on arbitrary regions; an uploaded scene's class predictions are not independently confirmed events. Segmentation is not a future forecast.

Flood-labelled pixel percentage = segmented valid pixels / all valid pixels. Estimated area uses georeferencing; neither metric independently confirms a flood.

AI Weather-Based Flood Risk Assessment

Rule based · not a trained AI model

Real Open-Meteo weather forecasts feed a transparent prototype rainfall-screening rule. The result is not an official warning, flood probability, river forecast, or validated flood-event prediction.

Loading weather module…

This is an experimental rainfall-based flood-risk screening tool. It does not confirm flooding or replace official warnings. Actual flood risk also depends on river levels, drainage, soil saturation, terrain, and local conditions. No validated future flood-event model is available in this project.

Weather data are for the selected coordinate or its forecast grid only, not an entire city, state, or river basin. Precipitation probability is not flood probability.
